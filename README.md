# 🧾 Receipt Parser AI

An AI-powered Receipt Parser application that extracts structured information from uploaded receipt images using OCR and LLM-based processing.

---

# 🚀 Live Demo

## Frontend
https://reciepts-pareser.vercel.app/

## Backend API
https://reciepts-pareser-3.onrender.com

---

# ✨ Features

- Upload receipt images
- OCR-based text extraction
- AI-powered receipt parsing
- Extract:
  - Store Name
  - Date
  - Items
  - Quantity
  - Prices
  - Total Amount
- Download parsed receipt data
- Responsive UI
- JSON-based data storage
- Real-time upload feedback

---

# 🛠 Tech Stack

## Frontend
- React
- TypeScript
- Tailwind CSS

## Backend
- Node.js
- Express.js
- TypeScript
- Multer

## OCR & AI
- Tesseract.js
- Groq LLM API
